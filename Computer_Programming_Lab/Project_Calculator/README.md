# C Programming – Console Calculator & Utility Application

A menu-driven console application developed using the **C programming language**. This project combines basic mathematical operations, a simple login verification system, and string case conversion in one program.

---

## Project Overview

This application allows users to perform different mathematical calculations and convert the letter cases of a given string through an interactive console menu. A basic username and password verification system is implemented before accessing the main application.

---

## Features

The application includes the following features:

### 1. Login Verification
* Username and password authentication.
* Repeated attempts until valid credentials are entered.

### 2. Addition
* Adds two numbers.
* Supports consecutive addition using the previous result.

### 3. Subtraction
* Subtracts one number from another.

### 4. Multiplication
* Multiplies two numbers.
* Supports consecutive multiplication using the previous result.

### 5. Division
* Divides a dividend by a divisor.

### 6. Square Root
* Calculates the square root of a positive number.
* Handles negative input by requesting a positive number.

### 7. Power Calculation
* Calculates a number raised to a given power using the `pow()` function.

### 8. Case Conversion
* Converts lowercase letters to uppercase.
* Converts uppercase letters to lowercase.
* Preserves spaces and other characters.

## Technologies & Concepts Used

* **Programming Language:** C
* **Standard Libraries:**
  * `stdio.h` – Input and output operations
  * `string.h` – String comparison and manipulation
  * `math.h` – Mathematical functions

### C Programming Concepts Practiced
* Functions and function declarations
* Global and local variables
* Conditional statements (`if-else`)
* Loops (`for`)
* User input and output
* String handling
* Arrays and character manipulation
* Mathematical operations
* Basic authentication logic
* Standard library functions such as `strcmp()`, `strlen()`, `sqrt()`, and `pow()`
